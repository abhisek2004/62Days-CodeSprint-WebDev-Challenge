User Guide & Capabilities

About WebAssembly VideoCraft Studio

This studio provides powerful, privacy-first video editing directly inside your web browser using HTML5 Canvas and simulated WebAssembly acceleration. No video is ever uploaded to any server!

Key Features:

  • Custom Watermarking: Overlay text with customizable fonts, stroke, shadow, colors, rotation, and opacity, or upload your own PNG/SVG logo.
  • Direct Drag & Position: Move watermark directly on the video canvas preview.
  • Keyframe Extractor: Automatically extract keyframes at configurable time intervals (0.5s, 1s, 2s, 5s, 10s) or fixed total frame counts.
  • ZIP Export: Download all or selected extracted keyframe thumbnails in a single ZIP file without external servers.
  • Local Encoding Pipeline: Encode watermarked video directly into WebM/VP9 using browser MediaRecorder.
