Studio User Guide

Procedural SFX Synthesizer

Select a fundamental waveform (Sine, Square, Saw, Triangle, or Noise). Adjust the start frequency and end frequency to create sweeps (e.g. descending pitches for lasers or explosions). Shape the sound envelope using ADSR sliders.

3D Spatial Audio Panner

Drag the cyan sound source node around the 2D grid relative to the listener (blue headphones node in the center). HRTF (Head-Related Transfer Function) calculates realistic 3D spatial cues, binaural pan, and distance attenuation when listened to with headphones.

Audio Exporter

Click "Render & Download .WAV" to capture lossless 16-bit PCM audio generated through `OfflineAudioContext` for instant use in games, apps, or video projects.
