# Calculator

A simple calculator built using **HTML**, **CSS**, and **JavaScript**. It performs basic arithmetic operations through a clean and straightforward user interface.

## Live Demo

🔗 **Live Website:** [https://your-live-link.com](https://mitali-kumari905.github.io/calculator/)

## Features

* Perform basic arithmetic operations:

  * Addition (+)
  * Subtraction (-)
  * Multiplication (×)
  * Division (÷)
* Clear the entire expression
* Delete the last entered character (Backspace)
* Display the entered expression
* Calculate and display results instantly

## Technologies Used

* HTML5
* CSS3
* JavaScript 

## How to Use

1. Open the live demo or download/clone this repository.
2. If running locally, open `index.html` in your browser.
3. Enter numbers and operators using the calculator buttons.
4. Click `=` to evaluate the expression.
5. Use `C` to clear the display.
6. Use the backspace (`⌫`) button to remove the last entered character.
