This project recreates the Netflix user interface and includes various frontend features inspired by the original Netflix experience.

## 🚀 Live Demo

🔗 **Live Link:** [https://mitali-kumari905.github.io/netflix-frontend-clone/]

## 📌 About The Project

This project is a frontend clone of Netflix created for learning and practice purposes.  
I have built a Netflix-inspired web application using modern frontend technologies with a focus on responsive design, UI interactions, and user experience.

The project includes frontend features similar to Netflix, such as:

- 🎬 Netflix-style homepage layout
- 🎥 Movie and TV show sections
- 🖼️ Hero banner section
- 🔥 Trending content sections
- 📂 Category-based movie rows
- 🎞️ Interactive UI components
- 🎨 Netflix-inspired dark theme design
- ⚡ Smooth frontend interactions using JavaScript

## 🛠️ Technologies Used

- **HTML5** – Structure and markup
- **Tailwind CSS** – Styling and responsive UI design
- **JavaScript** – Dynamic interactions and frontend functionality

## ✨ Features
